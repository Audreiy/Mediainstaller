# YuYuInstaller

[Türkçe](README.md) | [English](README_en.md)

YuYuInstaller — це сучасний завантажувач медіа та конвертер аудіо для Windows, розроблений на C++20 та Qt 6 Quick / QML. Програма має апаратно-прискорений аніме-відеофон, багатомовний інтерфейс (англійська, турецька, українська) та високопродуктивний рушій потокового завантаження.

---

## Osnovni Mozlyvosti

- **Suchasnyi ta Plavnyi Interfeis QML:**
  - Апаратно-прискорена темна аніме-тема на базі DirectX/Direct3D/Vulkan.
  - Відеофон з обмеженням 45 FPS; під час паузи фіксується на поточному кадрі подібно до плеєра YouTube з 0% навантаження на процесор (CPU) у стані спокою.
- **Vysokoshvydkisnyi Rushi Direct Stream:**
  - Архітектура прямого запису на диск через HTTP/HTTPS забезпечує блискавичну швидкість без перевантаження оперативної пам'яті.
- **Studiina Yakist MP3 320 kbit/s cherez FFmpeg:**
  - Вилучення аудіодоріжки без втрат якості та конвертація у кришталево чистий формат MP3 або AAC 320 kbps.
- **Pidtrymka Populiarnykh Platform ta Posylan:**
  - Автоматичне розпізнавання та отримання потоків із YouTube, Animecix (Tau Video), Vidmoly, Sibnet, TikTok, Instagram, Twitter (X) та прямих посилань на медіафайли.
- **Rozshyrena Cherha Zavantazhen:**
  - Одночасний (паралельний), послідовний та налаштовуваний ліміт завантажень.
  - Відображення поточної швидкості (MB/s), орієнтовного часу до завершення (ETA) та анімовані смуги прогресу.
  - Пауза, відновлення, скасування, очищення завершених завдань та швидке відкриття файлу в Провіднику Windows.
- **Bahatomovnist (i18n):**
  - Миттєве перемикання між англійською (за замовчуванням), турецькою та українською мовами на вкладці налаштувань.
- **Bezpechne Avtomatyczne Onovlennia:**
  - Перевірка оновлень через захищене з'єднання SSL/HTTPS безпосередньо з GitHub Releases. Завантаження інсталятора в один клік і безшовне оновлення програми у фоновому режимі з перезапуском.
- **Nadiinyi Instaliator dlia Windows:**
  - Збірка через Inno Setup 6 із сучасним оформленням, збереженням позиції ярлика на робочому столі та повним видаленням файлів без залишкового сміття.

## Instruktsiia Korystuvacha

Використовувати YuYuInstaller просто та зручно:

### 1. Dodavannia Mediaposylannia
* Скопіюйте посилання на відео або музику з підтримуваного сервісу (YouTube, Animecix, TikTok, Instagram тощо).
* Вставте посилання у поле введення на вкладці **Завантажувач (Downloader)** і натисніть **Аналіз (Analyze)**.

### 2. Vybir Formatu ta Yakosti
* Після завершення аналізу з'явиться картка з інформацією про медіафайл:
  * **Відео (MP4 / Найкраща якість):** Відео найвищої роздільної здатності з повноцінним зведеним звуком.
  * **Лише аудіо (320 kbps MP3):** Чиста аудіодоріжка студійної якості 320 кбіт/с, оброблена через FFmpeg.
* За бажанням можна вибрати іншу папку збереження за допомогою кнопки **Змінити папку (Change Folder)**.

### 3. Zavantazhennia ta Keruvannia Cherhoiu
* Натисніть кнопку **Почати завантаження (Start Download)**.
* Завдання автоматично перейде на вкладку **Черга завантажень (Queue)**.
* На вкладці черги ви можете:
  * Стежити за реальною швидкістю завантаження (MB/s) та залишковим часом (ETA).
  * Призупиняти, відновлювати або скасовувати завантаження в будь-який момент.
  * Після завершення натиснути **Відкрити папку (Open Folder)**, щоб одразу перейти до завантаженого файлу в Провіднику Windows.

### 4. Naloshtuvannia Prohramy
* На вкладці **Налаштування (Settings)** ви можете:
  * **Мова інтерфейсу:** Перемикатися між англійською (EN), турецькою (TR) та українською (UA).
  * **Анімований відеофон:** Увімкнути або зупинити анімацію тла за допомогою зручного перемикача (пауза фіксує кадр без споживання ресурсів).
  * **Папка завантажень за замовчуванням:** Змінити шлях, куди автоматично зберігатимуться нові файли.
  * **Статус рушіїв:** Перевірити наявність та готовність до роботи утиліт FFmpeg та yt-dlp.

## Stek Tekhnolohii

* **Основна мова:** C++20 (MSVC 2026)
* **Графічний інтерфейс:** Qt 6.8 (Qt Quick, QML, Qt Quick Controls 2)
* **Рендеринг відео:** Windows Media Foundation (`mfplat`, `mfreadwrite`), QQuickFramebufferObject
* **Медіаутиліти:** FFmpeg 7.x, yt-dlp
* **Створення інсталятора:** Inno Setup 6 (Modern Wizard, LZMA2 Ultra Compression)

## Struktura Proiektu

```text
YuYuInstaller/
├── CMakeLists.txt              # Конфігурація збірки CMake та реєстрація QML модулів

├── make_setup.bat              # Скрипт створення файлу інсталятора (Setup.exe)

├── assets/                     # Логотипи, іконки та фонове відео
├── src/
│   ├── main.cpp                # Точка входу та ініціалізація рушія QML
│   ├── core/                   # Завантажувачі, аналізатори потоків та менеджер черги
│   ├── media/                  # Рендеринг відео через Media Foundation та FFmpeg
│   └── models/                 # Реактивні моделі списків для QML
└── qml/
    ├── Main.qml                # Головне вікно програми
    ├── Theme.qml               # Дизайн-система, колірна палітра та стилі
    ├── I18n.qml                # Синглтон багатомовності (EN/TR/UA)
    ├── components/             # Багаторазові компоненти інтерфейсу
    └── views/                  # Головні сторінки (Dashboard, Queue, Settings, Updates)
```

## Zbirka z Vykhidnoho Kodu

### Systemni Vymohy
* Windows 10 / 11 (64-bit)
* Visual Studio 2022 / 2026 (компоненти розробки класичних додатків C++)
* Qt 6.8+ (MSVC 2022 64-bit)
* CMake 3.20+ та Ninja
* Inno Setup 6 (для створення установочного пакета)

### Instruktsiia zi Zbirky

1. **Клонуйте репозиторій:**
   ```powershell
   git clone https://github.com/Audreiy/Mediainstaller.git
   cd Mediainstaller
   ```

2. **Зберіть проєкт:**
   ```powershell
   .\build.bat
   ```

3. **Розгорніть залежності Qt:**
   ```powershell
   .\deploy.bat
   ```

4. **Створіть інсталятор (за потреби):**
   ```powershell
   .\make_setup.bat
   ```
   *Готовий інсталятор буде збережено у папці `setup_output\YuYuInstaller_Setup.exe`.*
